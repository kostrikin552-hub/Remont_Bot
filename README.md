## 1. Введение и позиционирование продукта

**Remont_Bot** — это специализированная цифровая B2B SaaS платформа, созданная для того, чтобы превращать холодный входящий трафик из Telegram-каналов, чатов новостроек и таргетированной рекламы в **твердые, юридически защищенные договоры на ремонт квартир под ключ**.

Платформа решает главную проблему современного строительного бизнеса в сегменте отделки жилой недвижимости: **разрыв между ожиданием заказчика и коммерческим предложением строителя**. Вместо пугающих Excel-файлов на 200 строк клиент получает элегантное, мгновенное Telegram Mini App приложение, которое за 20 секунд считает честную прозрачную смету, доказывает отсутствие скрытых накруток и закрывает человека на бесплатный лазерный замер.

Для строительных компаний и частных прорабов Remont_Bot выступает полноценным **лидогенератором и CRM-фильтром «под ключ»**, отсекающим нецелевой трафик и привлекающим платежеспособных клиентов с ключами на руках.

## 2. Проблематика рынка: боли клиентов и прорабов

### Боли заказчиков ремонта (B2C-сегмент):

1. **Страх скрытых накруток («Смета-айсберг»):**  
   Частные бригады на Авито и сайтах объявлений называют демпинговую цену «от 3 990 ₽/м²». После захода на объект смета обрастает доплатами: *«штробление бетона считается отдельно», «вынос мусора не входит», «грунтовка в 3 слоя — за доплату»*. В итоге цена вырастает на 40–80%, приводя к скандалам и судам.
2. **Сложность и непонятность смет:**  
   Классическая смета строительной компании представляет собой PDF-файл из сметной программы (ГРАНД-Смета) на 15 листов с непонятными коэффициентами, трудозатратами и аббревиатурами. Обычный новосел впадает в ступор и чувствует себя уязвимым.
3. **Отсутствие дизайн-проекта у 75%+ заказчиков:**  
   Большинство сервисов требуют загрузить готовый альбом чертежей. Но у 3 из 4 новоселов есть только план БТИ от застройщика. Они боятся обращаться к крупным компаниям, считая, что без дизайнера за 200 000 ₽ с ними не станут разговаривать.
4. **Страх потери аванса:**  
   Рынок полон историй, когда строители брали аванс 30–50% за работу и исчезали либо затягивали сроки на полгода.

### Боли прорабов и строительных фирм (B2B-сегмент):

1. **Астрономическая стоимость лида (CPA):**  
   В Москве, Санкт-Петербурге и городах-миллионниках стоимость одного реального замера через Яндекс Директ или таргетированную рекламу колеблется **от 3 500 до 8 000 ₽**.
2. **До 60% холодных и нецелевых выездов:**  
   Замерщики и прорабы тратят бензин и рабочее время на выезды к клиентам, у которых «дом сдастся только через полтора года», «мы просто прицениваемся» или «хотим сделать трешку за 200 000 рублей».
3. **Демпинг со стороны «диких бригад»:**  
   Честному мастеру, соблюдающему строительные нормы СП 71.13330 (маяки, грунтовка, гидроизоляция), сложно объяснить клиенту, почему его работа стоит 18 000 ₽/м², когда рядом частник обещает сделать за 8 000 ₽/м².
4. **Потеря времени на ручные расчеты:**  
   На ручной подсчет одной сметы по проекту прораб тратит 4–6 часов вечера. Если из 5 расчетов договор подписывает только один, до 20 часов рабочего времени в неделю тратится впустую.

## 3. Целевая аудитория (Глубокие портреты B2C и B2B)

### Сегмент B2C (Конечные клиенты — заказчики ремонта):

| Сегмент | Портрет и контекст | Главный триггер покупки | Что отталкивает |
| :--- | :--- | :--- | :--- |
| **Новоселы в бетоне (Новостройка)** | Семья 28–42 года, взяли ипотеку. Квартира без отделки. Бюджет жестко ограничен остатком накоплений. | **0% аванса, фиксированная цена в договоре, точные сроки**. | Заниженные сметы с риском роста цен; требование предоплаты. |
| **White Box новоселы** | Стяжка и штукатурка есть от застройщика. Хотят быстро заехать, не переплачивая за черновую отделку. | **Скидка на черновой этап (-25%), быстрая смета на финиш**. | Навязывание повторного оштукатуривания. |
| **Покупатели вторички** | Семья, купившая квартиру в старом фонде/панельке. Нужен капитальный демонтаж. | **Понимание объемов демонтажа, вывоз мусора, выравнивание стен под 90°**. | Скрытые доплаты за слом перегородок и дранку. |
| **Бизнес-класс и апартаменты** | Заказчики с чеком от 2.5 млн ₽. Нужна качественная инженерия (Rehau, Far, шумоизоляция). | **Официальное КП по ГОСТ, коллекторный узел, 36 мес. гарантии**. | «Колхозный» подход частников без договора. |

### Сегмент B2B (Покупатели платформы Remont_Bot):

1. **Частные прорабы и бригадиры (1–3 бригады):**
   - *Потребность:* Автоматический приток целевых лидов из чатов ЖК без найма маркетологов и создания дорогих сайтов за 150 000 ₽.
   - *Ценность бота:* Готовая персональная ссылка на бота, которую можно отправить заказчику в WhatsApp/Telegram или разместить в шапке профиля.
2. **Отделочные компании среднего масштаба (5–15 бригад):**
   - *Потребность:* Стандартизация воронки продаж, скоринг заявок, разгрузка замерщиков от пустых выездов.
   - *Ценность бота:* Фильтрация лидов по статусу ключей (0–100 баллов), единые корпоративные расценки на 35 позиций, официальная печать КП в PDF.
3. **Маркетологи и лидогенераторы в строительной нише:**
   - *Потребность:* Высокая конверсия трафика в заявку (CR из клика в лид от 12% до 22%).
   - *Ценность бота:* Конверсия Telegram Mini App в 2.5–3 раза выше стандартных лендингов за счет нативности и отсутствия авторизаций.

│ 5. ЗАКРЫТИЕ НА ДЕЙСТВИЕ:                                               │

### Структура базы данных (PostgreSQL / Supabase)

#### 1. Таблица `companies` (Тенанты строительных компаний):
```sql
CREATE TABLE public.companies (
    id TEXT PRIMARY KEY,                       -- Уникальный идентификатор компании (slug / UUID)
    name TEXT NOT NULL,                        -- Название («РемонтПро», «СК Монолит»)
    subtitle TEXT DEFAULT 'Калькулятор ремонта',
    city TEXT NOT NULL DEFAULT 'Москва и МО',  -- Город присутствия
    phone TEXT NOT NULL,                       -- Телефон прямого вызова прораба
    status_text TEXT DEFAULT 'Без предоплаты', -- УТП плашка
    secondary_coeff NUMERIC(4, 2) DEFAULT 1.15,-- Коэффициент сложности вторички
    logo_letter TEXT DEFAULT 'Р',
    badge_text TEXT DEFAULT 'PRO',
    admin_chat_id BIGINT,                      -- Telegram ID владельца (доступ к ценам и CRM)
    bot_token_encrypted TEXT,                  -- Зашифрованный токен бота (@BotFather)
    bot_username TEXT,                         -- Юзернейм бота в Telegram
    subscription_status TEXT DEFAULT 'trial',  -- 'trial' | 'active' | 'expired'
    subscription_until TIMESTAMP WITH TIME ZONE,
    trial_leads_used INT DEFAULT 0             -- Счетчик бесплатных лидов (лимит: 3)
);
```

#### 2. Таблица `pricing_rules` (Индивидуальные расценки на ремонт):
```sql
CREATE TABLE public.pricing_rules (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    company_id TEXT REFERENCES public.companies(id) ON DELETE CASCADE UNIQUE NOT NULL,
    cosmetic_price NUMERIC(10, 2) NOT NULL DEFAULT 4500,     -- Косметический (руб/м²)
    capital_price NUMERIC(10, 2) NOT NULL DEFAULT 8500,      -- Капитальный под ключ (руб/м²)
    designer_price NUMERIC(10, 2) NOT NULL DEFAULT 15000,    -- Дизайнерский (руб/м²)
    design_project_price NUMERIC(10, 2) NOT NULL DEFAULT 2000,
    demolition_price NUMERIC(10, 2) NOT NULL DEFAULT 1200,
    materials_price NUMERIC(10, 2) NOT NULL DEFAULT 3500
);
```

#### 3. Таблица `leads` (Заявки на замер с защитой по 152-ФЗ):
```sql
CREATE TABLE public.leads (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    company_id TEXT REFERENCES public.companies(id) ON DELETE SET NULL,
    contact_channel TEXT DEFAULT 'telegram',
    preferred_date TEXT,
    housing_type TEXT NOT NULL,
    repair_type TEXT NOT NULL,
    area_m2 NUMERIC(8, 2) NOT NULL,
    options JSONB DEFAULT '[]'::jsonb,
    min_cost NUMERIC(12, 2) NOT NULL,
    max_cost NUMERIC(12, 2) NOT NULL,
    status TEXT DEFAULT 'new_open',
    encrypted_payload TEXT NOT NULL DEFAULT '', -- AES-256 Fernet payload (152-ФЗ)
    lead_score INT DEFAULT 50,                  -- Скоринг готовности лида (0..100)
    lead_grade TEXT DEFAULT 'warm',             -- 'vip' | 'warm' | 'cold'
    is_visit_allowed BOOLEAN DEFAULT true       -- Разрешен ли физический выезд замерщика
);
```

## 6. Функциональные модули и подсистемы Mini App

### 6.1. Якорный трекер этапов расчета (`StepWizardNav`)
* Расположен вверху рабочей области с поддержкой плавного скролла и **Scroll Spy** (автоматическая подсветка текущего этапа по координатам вьюпорта).
* 4 логических шага:
  - `1. Объект` (тип и площадь)
  - `2. Тариф` (класс ремонта)
  - `3. Опции` (санузлы, потолки, материалы)
  - `4. Смета` (итоговый бюджет и замер)

### 6.2. Симметричный селектор 6 типов недвижимости
Сетка сбалансирована по схеме **3×2 на смартфонах и 2×3 на десктопе** без пустых ячеек:
1. **Новостройка: Бетон** (Базовый расчёт, стены от застройщика, полный черновой цикл).
2. **Новостройка: White Box** (Скидка -25% на черновой этап, стяжка и штукатурка уже есть).
3. **Свободная планировка** (Добавочный расчет на возведение перегородок из блоков).
4. **Вторичка (Панель/Кирпич)** (Коэффициент сложности ×1.15 на стандартный демонтаж).
5. **Старый фонд / Сталинка** (Коэффициент ×1.45 на сложный демонтаж дранки и лаг пола).
6. **Апартаменты / Таунхаус** (Бизнес-класс: усиленная шумоизоляция, вентиляция, панорамные зоны).

### 6.3. Интерактивный слайдер площади и пресеты комнатности
* Диапазон от 20 до 250 м² с шагом 1 м² и возможностью ручного ввода с клавиатуры.
* Быстрые пресеты типового жилья в 1 клик:
  - `Студия (28 м²)`
  - `1-комнатная (42 м²)`
  - `2-комнатная (65 м²)`
  - `3-комнатная (85 м²)`

### 6.4. 3 тарифа отделки и технологические карты
1. **Косметический (от 4 500 ₽/м²):**  
   Чистовое обновление без переноса стен и сантехники (переклейка обоев, настил ламината, натяжной потолок, замена розеток).
2. **Капитальный под ключ (Хит продаж, от 8 500 ₽/м²):**  
   Полный цикл по СП 71.13330 (стяжка пола по маякам с фиброволокном, штукатурка стен по маякам под 90°, разводка электрики ГОСТ ВВГнг-LS в гофре, лучевая сантехника Rehau/Stout, укладка керамогранита с СВП, финишная шпаклевка).
3. **Индивидуальный дизайн (от 15 000 ₽/м²):**  
   Сложные проектные решения (теневые плинтусы, скрытые двери Invisible, крупноформатный керамогранит 1200×600 с запилом под 45°, трековое освещение, звукоизоляция).

### 6.5. Инженерный калькулятор геометрии и санузлов

## 7. B2B SaaS возможности для строительного бизнеса

### 7.1. Мультитенантный онбординг прораба за 2 минуты
Любой мастер или строительная фирма подключается к системе без единой строчки кода:
1. Создает бота в Telegram через официального `@BotFather` за 1 минуту и копирует токен.
2. Открывает мастер-бота платформы `@RemontMasterBot` и нажимает «Подключить бота компании».
3. Вводит токен ➔ бэкенд на Express регистрирует нового тенанта в Supabase, настраивает Webhook и привязывает Mini App URL.
4. Бот сразу готов принимать заявки от клиентов и слать уведомления лично прорабу.

### 7.2. Модель монетизации и Soft Paywall
* **Trial-период (3 бесплатных лида):**  
  Каждый новый прораб бесплатно получает первые 3 заявки на замер с открытыми номерами телефонов клиентов, чтобы лично убедиться в работоспособности и качестве заявок.
* **Механика Soft Paywall:**  
  Начиная с 4-й заявки телефон клиента маскируется: `+7 (999) ***-**-**`, а прорабу отправляется сообщение с кнопкой: *«У вас новая целевая заявка на 1 250 000 ₽! Активируйте подписку, чтобы открыть контакты»*.

### 7.3. Интеграция оплат: ЮKassa и Telegram Payments
* Прораб может оплатить подписку прямо внутри Telegram:
  - Банковскими картами РФ (МИР, Visa, Mastercard) через шлюз ЮKassa.
  - Через Систему быстрых платежей (СБП) по QR-коду.
  - Нативными Telegram Stars.
* Автоматическая валидация вебхуков оплаты по алгоритму HMAC-SHA256: при подтверждении транзакции статус подписки в базе переключается на `active`, а замаскированный лид мгновенно расшифровывается прорабу в чат.

### 7.4. «Железный занавес» и изоляция коммерческих расценок
* Редактор цен (`/pricing`) строго изолирован:
  - Доступ разрешен **исключительно владельцу бота** (проверяется цифровой ID пользователя Telegram `window.Telegram.WebApp.initDataUnsafe.user.id`).
  - Сторонние клиенты или конкуренты при попытке открыть редактор немедленно перенаправляются обратно в калькулятор.
  - Ликвидированы все небезопасные URL-параметры (`?admin_id=...`).
  - Вне Telegram доступ защищен мастер-паролем с блокировкой на 60 секунд после 5 неверных попыток.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/kostrikin552-hub/Remont_Bot.git
   cd Remont_Bot
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте файл переменных окружения `.env`:**
   ```env
   PORT=3000
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Запустите режим разработки:**
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000`.

5. **Проверка типизации и сборка:**
   ```bash
   npm run lint   # Проверка TypeScript без ошибок (tsc --noEmit)
   npm run build  # Production-сборка в каталог dist/
   npm run start  # Запуск production full-stack сервера
   ```
