## 1. Ключевой технологический ров: Gemini Flash AI-Сметчик

Обычные строительные калькуляторы считают бюджет по статичным формулам. Наше решение использует **мультимодальное зрение и длинный контекст (1M+ токенов) Gemini Flash**, решая главную рутинную боль прораба — ручной просчет сложных дизайн-проектов.

```
┌──────────────────────────┐      ┌──────────────────────────┐      ┌──────────────────────────┐
│   PDF Дизайн-проекта     │      │     Gemini Flash 2.5     │      │   Интерактивная смета    │
│  (альбом до 100 страниц) ├─────►│  Мультимодальное зрение  ├─────►│     по 35 видам работ    │
│  или скан сметы бригады  │      │  (извлечение + коллизии) │      │      и официальное КП    │
└──────────────────────────┘      └──────────────────────────┘      └──────────────────────────┘
```

### Что делает AI-модуль за 15 секунд:
1. **Автоматическое извлечение физических объемов:**
   - Распознает общую и жилую площадь по экспликациям.
   - Подсчитывает силовые и слаботочные розетки, выводы освещения.
   - Рассчитывает точки ХВС/ГВС, трассы канализации и коллекторные группы.
   - Вычисляет квадратуру укладки керамогранита и плитки в санузлах.
2. **Аудит скрытых коллизий и нарушений нормативной базы:**
   - Нарушения ПУЭ-7 (например, размещение розеток ближе 60 см от мокрых зон).
   - Несоответствия СП 71.13330.2017 (отсутствие гидроизоляционных лент в зоне душевого поддона).
3. **Разоблачение скрытых доплат в сметах конкурентов:**
   - Сканирует сметы частных мастеров и выявляет искусственно «забытые» пункты (штробление бетона, подъем тяжелых смесей на этаж, вывоз мусора).
4. **Бесшовный перенос в калькулятор:**
   - Нажатием кнопки **«Применить к калькулятору»** все параметры мгновенно подставляются в смету с актуальными расценками прораба.
5. **Встроенные быстрые демо-проекты:**
   - Для тестирования без загрузки файлов внедрены готовые пресеты: *Дизайн-проект 2К ЖК «Скандинавия» (64.5 м²)* и *Смета частников с уловками на +144 000 ₽*.

## 2. Продуктовые возможности и конверсионный UX

Интерфейс спроектирован по стандартам **Anti-AI Slop**: строгая инженерно-технологичная эстетика, отсутствие размытых кислотных градиентов, моноширинные технические цифры (`font-mono`) и реальные строительные стандарты (СНиП / СП / ГОСТ).

### Ключевые компоненты:
* **Единый экран расчёта (Отказ от путаницы «Мастер / Сводка»):**
  - Клиенту больше не нужно выбирать между абстрактными режимами.
  - Верхний интерактивный якорный трекер со **Scroll Spy** (`1. Объект` ➔ `2. Тариф` ➔ `3. Опции` ➔ `4. Смета`) плавно прокручивает страницу и показывает текущий прогресс.
* **Интерактивный блок «Анти-обман» (`CompetitorTruthTable`):**
  - Таблица сравнения: условия «диких бригад» против нашего инженерного стандарта ГОСТ.
  - Разбор 5 главных уловок рынка с точными суммами скрытых доплат (штробы +55 000 ₽, грунтовка +30 000 ₽, углы 90° +40 000 ₽, мусор +35 000 ₽, гидроизоляция +25 000 ₽).
* **Сертификат фиксации цены на 14 дней (`PriceLockCard`):**
  - Юридическая защита от подорожания материалов и работ.
  - Прозрачное соотношение: Работа мастеров vs Черновые материалы.
  - Гарантии: **0% аванса за работы**, оплата поэтапно по актам КС-2, гарантия **36 месяцев** в договоре.
* **Генератор коммерческого предложения для печати в PDF (`PrintProposalModal`):**
  - Чистая верстка формата A4 для официальной печати (`window.print()`).
  - Полный перечень работ по 35 пунктам, реквизиты компании, паспортные данные клиента и место для печати (М.П.).
* **Прямая связь в 1 клик:**
  - Кнопка быстрого вызова прораба по телефону в шапке приложения.
  - Запись на бесплатный замер с лазерным дальномером (0 ₽).

## 3. Безопасность и «Железный занавес» редактора цен

Редактор расценок и панель управления B2B SaaS защищены многоуровневой системой изоляции. **Ни один посторонний пользователь не имеет возможности просмотреть или изменить расценки владельца.**

```
                                 [Попытка входа в /pricing]
                                             │
                       ┌─────────────────────┴─────────────────────┐
                       ▼                                           ▼
             [Внутри Telegram]                             [Вне Telegram (Web)]
                       │                                           │
         ID === '5629144056'?                               Форма с маскированным
           /              \                                 вводом мастер-пароля
         Да               Нет                                      │
         │                 │                               Лимит: 5 попыток
      Доступ          Моментальный                                 │
     разрешён      возврат в калькулятор                   Блокировка на 60 сек
```

### Защитные механизмы:
1. **Изоляция по нативному Telegram ID:**
   - Telegram WebApp SDK передает проверенный цифровой ID пользователя (`window.Telegram.WebApp.initDataUnsafe.user.id`).
   - Если ID не равен `5629144056`, доступ закрывается аппаратно, а пользователя моментально возвращает в клиентский калькулятор.
2. **Ликвидация URL-лазеек:**
   - Полностью вырезаны любые проверки параметров `?admin_id=...` и `?user_id=...`. Передать чужой ID через ссылку технически невозможно.
3. **Защита от перебора паролей (Brute-force protection):**
   - При открытии вне Telegram в компоненте `AdminAccessGate` включен лимит: после 5 неверных попыток форма блокируется на 60 секунд.
4. **Чистый клиентский интерфейс:**
   - Кнопки «Цены» и «Бот & БД» отображаются в шапке **только при подтвержденной сессии владельца**. В публичном футере любые ссылки на редактор расценок отсутствуют.

## 4. Бизнес-модель и Zero-CAC стратегия

### Целевые сегменты и готовность платить:
* **Частные мастера:** покупка готового бота под ключ (**9 900 – 14 900 ₽ разово**) или подписка (**1 500 – 2 500 ₽/мес**).
* **Прорабы с бригадами (3–5 объектов):** подписка **3 900 – 5 900 ₽/мес** за экономию 15 часов на сметах и отсечение нецелевых выездов.
* **Строительные компании:** White-Label SaaS **7 500 – 15 000 ₽/мес** с брендированием, реквизитами и печатью договоров.

### Скрипт холодного аутрича без бюджета (Zero-CAC на 100 прорабов):
1. Находим в Telegram-чатах («Клуб прорабов», «Отделочники Москвы») контакты прорабов.
2. Прогоняем через AI-сканер типовой дизайн-проект квартиры из жилого комплекса, где прораб ведет работы.
3. Отправляем короткое сообщение с готовой пользой:
   > *«Сергей, добрый день! Видел ваши работы в ЖК "Скандинавия". Я обучил строительную нейросеть разбирать чертежи за 15 секунд. Прогнал проект из вашего ЖК — модель за секунды нашла 3 коллизии на 95 000 ₽ (ошибка с розетками у мойки и отсутствие гидроизоляции) и собрала точную смету по ГОСТ. Держите готовый PDF. Хотите так же быстро считать сметы на своих замерах со смартфона? Дам бесплатный доступ на 3 объекта»*.
4. **Конверсия:** от 25% до 40% в тест и оплату.

* **Telegram Integration:** Telegram WebApp SDK (Haptic feedback, MainButton, BackButton, глубокие ссылки).
* **Стилизация:** Tailwind CSS v4 через директиву `@import "tailwindcss";`.

## 7. Инструкция по установке и локальному запуску

### Предварительные требования:
* **Node.js** версии 20.0 или выше.
* **npm** версии 9.0 или выше.
* API ключ Gemini (**GEMINI_API_KEY**).

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/remont-bot.git
   cd remont-bot
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта:
   ```env
   PORT=3000
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Запустите full-stack сервер разработки:**
   ```bash
   npm run dev
   ```
   Сервер запустится на адресе `http://localhost:3000` (одновременно обслуживая API роуты Express и Vite frontend).

5. **Проверка качества кода:**
   ```bash
   npm run lint
   ```

## 8. Развертывание в Production

1. **Сборка клиентской части:**
   ```bash
   npm run build
   ```
   Скомпилированные статические файлы будут помещены в директорию `dist/`.

2. **Запуск production-сервера:**
   ```bash
   npm run start
   ```
   Сервер `server.ts` автоматически отдаёт статику из `dist/` и обрабатывает API-запросы `/api/gemini/*`.
